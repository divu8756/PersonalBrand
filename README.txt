Divyanshu Srivastava — personal site (multi-file, CodeStorm-style)

STRUCTURE
  index.html                 The page (structure + views)
  assets/css/styles.css      All styling (light/dark themes, responsive)
  assets/js/data.js          Your content — EDIT THIS to change text/links
  assets/js/app.js           Rendering, tab routing, charts, contact form
  assets/img/profile.jpg     Your profile photo

RUN
  Just open index.html in any browser (double-click). No build step.
  For the Chart.js analytics + Google Fonts you need an internet connection.

EDIT
  - Text, experience, skills, certifications, links: assets/js/data.js
  - Colors / layout: assets/css/styles.css (CSS variables at the top)
  - Swap the photo: replace assets/img/profile.jpg (square image works best)
  - Resume link + email: profile.resume / profile.email in data.js

DEPLOY
  Upload the whole folder to any static host (GitHub Pages, Netlify, Vercel,
  or your own server). index.html must sit next to the assets/ folder.
